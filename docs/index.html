segment-lidar 0.3.0

Project LiDAR clouds to images, find objects with SAM 3, and transfer labels to 3D points.

The animation uses 5,556,802 RGB points from the Sao Paulo M3DC aerial LiDAR archive, licensed under GPL 3.0. The buildings and tree prompts generated 124 masks. After overlap was resolved, 115 visible labels reached 2,907,279 points. The 1600 by 900 perspective animation draws a fixed 1,600,000 point sample from the urban part of the tile. Building instances use warm colors, tree instances use green colors, and gray means no label.

Get access to SAM 3

  1. Sign in and open the SAM 3 model page.
  2. Read the conditions, request access, and agree to share the requested information with Meta. Wait for approval if review is required.
  3. Create a Hugging Face token with read access to the model.
  4. Provide the token as HF_TOKEN or pass it as hf_token to SamLidar.

Access requests must be made in a browser. A token from an account without approval cannot download the model.

Install

python -m pip install "segment-lidar[sam3]"

Python 3.10 or newer is required. A CUDA GPU is recommended for inference.

Automatic masks

from segment_lidar import SamLidar, TopView
model = SamLidar(resolution=0.25)
points = model.read("pointcloud.las")
ids, labels, image = model.segment(points, view=TopView())
model.write(points, ids, save_path="segmented.las")

The SAM 3 mask generation pipeline samples a 32 by 32 point grid by default. Set model.automatic_masks.points_per_crop to change grid density. The model loads from Hugging Face on the first inference call and runs locally after download. The token is never written to output files.

Text prompt

ids, labels, image = model.segment(points, prompt="tree")

Box prompts

Use image pixel coordinates in the form [left, top, right, bottom]. Label 1 means include and 0 means exclude. Text and boxes may be combined.

ids, labels, image = model.segment(
    points, prompt="tree",
    boxes=[[80, 40, 180, 220], [210, 30, 300, 160]],
    box_labels=[1, 0],
)

Saved labels

Provide image_exists=True and label_exists=True to use saved rasters without a token. Raster value 0 is background; unmatched points receive -1. Top view rasters include a spatial transform so a subset of the cloud can use a saved image.

Docker

The image includes the SAM 3 runtime. Supply your token only at run time through a local .env file.

docker build -t segment-lidar:0.3.0 .
docker run --rm --gpus all --env-file .env -v "$PWD/data:/data" \
  segment-lidar:0.3.0 python /data/process.py
