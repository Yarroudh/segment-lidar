segment-lidar documentation

segment-lidar projects a LiDAR point cloud to a 2D image, finds object instances with Meta’s SAM 3, and assigns the image labels back to the original 3D points. It supports top and pinhole views, automatic masks, text and box prompts, optional ground filtering, cached rasters, and LAS/LAZ output.

The current API is the 0.3 series. SAM 3 replaces the SAM 1 checkpoint workflow described in documentation published before 0.3. See Migrating from the earlier documentation when updating an older script.

How the pipeline works

read loads XYZ or XYZRGB points. An optional csf call removes ground points. segment projects the remaining points with TopView or PinholeView, runs SAM 3 or reads saved labels, and transfers the labels to points. write stores a signed 32 bit segment_id extra dimension in LAS/LAZ.

The image label 0 is background. Point label -1 means background or outside the image; positive values identify instances. When several points project to one pixel, they can receive the same instance label.

from segment_lidar import SamLidar, TopView

model = SamLidar(resolution=0.25)
points = model.read("pointcloud.las")
ids, labels, image = model.segment(points, view=TopView(), prompt="tree")
model.write(points, ids, save_path="segmented.las")
