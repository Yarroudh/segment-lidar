Citation
========

If you use this repository in research, cite the accompanying
`CITATION.bib <https://github.com/Yarroudh/segment-lidar/blob/main/CITATION.bib>`_:

.. code-block:: bibtex

   @misc{yarroudh:2023:samlidar,
     author = {Yarroudh, Anass},
     title = {LiDAR Automatic Unsupervised Segmentation using Segment-Anything Model (SAM)},
     year = {2023},
     howpublished = {GitHub Repository},
     url = {https://github.com/Yarroudh/segment-lidar}
   }

Also follow the citation and licensing requirements of the model and data
used in your work.
